STATUS INTEGRASI GOOGLE DRIVE Belum Terhubung Tempelkan URL Web App Google Apps Script di bawah untuk mengaktifkan sinkronisasi otomatis.

⚡ 3 Langkah Mudah Menghubungkan Google Drive Anda:

1. Buat Script di Google: Buka script.google.com ↗ (login dengan akun Google Anda), klik New Project, lalu ganti isinya dengan kode di bawah:
2. Deploy sebagai Web App: Klik tombol biru Deploy (kanan atas) → New deployment → Klik icon ⚙️ pilih Web app → Set Execute as: Me dan Who has access: Anyone → Klik Deploy → Salin Web app URL yang dihasilkan.
3. Tempel URL & Selesai: Tempelkan Web App URL tersebut pada form di bawah dan klik Simpan & Aktifkan.
